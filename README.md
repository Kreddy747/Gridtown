# Gridtown

Interactive learning tool about large-load network contributions, risk and flexibility. All numerical assumptions are fictional. The model is network-only and is not a household bill calculator. Specialist review remains necessary before treating it as validated training material.

This project was developed with substantial AI assistance and human direction. It is a static HTML/CSS/JavaScript website with no server-side computation or build pipeline.

## Publication

Place these files at the root of the `pages` branch in a Codeberg repository. Configure a Forgejo webhook with target `https://USERNAME.codeberg.page/REPOSITORY/` and branch filter `pages`, then push/upload the files. Substitute the actual account and repository names.
